# Supply Chain Crossword

A 12-word crossword with riddle clues on inventory and lean operations. Plays in any browser, no install or build step. Answers are checked only when the player presses **Submit**, which works at any time, even if the grid is incomplete.

## Play online with GitHub Pages
1. Push these files to a GitHub repository (index.html must be in the root).
2. Open the repository's **Settings > Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then Save.
4. After about a minute the game is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Run locally
Open `index.html` in a browser.

## Edit the words
Clues and answers are in the `W` array near the top of the script in `index.html`. The grid layout depends on which words cross, so changing words means re-laying the grid.
